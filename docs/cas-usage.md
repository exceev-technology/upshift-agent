# Fiche de cas d'usage

Une fiche par scénario retenu (§06). Les cas du sujet sont des pistes : ils ne remplacent pas les conclusions de l'équipe. Une hypothèse non confirmée par le terrain est indiquée comme telle.

## Démarche de sélection

1. Décrire l'activité, les utilisateurs et le parcours actuel.
2. Identifier une tâche répétitive ou une rupture de suivi observable.
3. Vérifier que les données nécessaires existent dans le CRM ou peuvent y être ajoutées.
4. Définir ce que l'agent peut décider et ce qui reste une décision humaine.
5. Choisir une progression simple, puis un parcours commercial complet avec un résultat vérifiable.
6. Justifier la sélection ; écarter les scénarios trop risqués ou trop dépendants d'intégrations.
