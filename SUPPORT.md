# Obtenir de l'aide

| Besoin | Où |
| --- | --- |
| Une question sur le projet, le SDK ou Upshift | [Discussions · Q&A](https://github.com/exceev-technology/upshift-agent/discussions/categories/q-a) |
| Une idée, une proposition d'agent ou de skill | [Discussions · Ideas](https://github.com/exceev-technology/upshift-agent/discussions/categories/ideas) |
| Un bug reproductible | [Nouvelle issue · Bug](https://github.com/exceev-technology/upshift-agent/issues/new?template=2-bug.yml) |
| Une faille de sécurité | [Signalement privé](https://github.com/exceev-technology/upshift-agent/security/advisories/new), jamais en public |
| Comprendre l'organisation, Scrum, Git ou Upshift | [Wiki du projet](https://github.com/exceev-technology/upshift-agent/wiki) |
| Utiliser Upshift | [Documentation Upshift](https://docs.upshiftcloud.com/en/getting-started/introduction) |

**Équipe du projet :** blocages et questions du quotidien dans le canal Slack `#ecc-bootcamp-upshift-agent`, en fil de discussion. Bloqué·e depuis plus d'une demi-journée ? Écrivez-le, c'est fait pour ça.

Avant de poser une question, cherchez dans les discussions et les issues existantes : la réponse y est peut-être déjà.
